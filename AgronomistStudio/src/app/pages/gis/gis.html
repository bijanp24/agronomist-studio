Agronomic Learning Guide & Formulas

Shoelace Formula

Cartesian polygon coordinates evaluated via centroid-scaled projection:

Area = 1/2 |Σ(x_i y_{i+1} - x_{i+1} y_i)|
D8 Flow Dynamics

Calculates slope rise over run to 8 adjacent neighbors. Flow is assigned to the neighbor of maximum descent drop.

Slope % = (elev_c - elev_n)/dist * 100
Logistic Growth ODE

Population growth bounded by resource ceilings modeled using Euler ODE integration steps:

dN/dt = r * N * (1 - N / K)
